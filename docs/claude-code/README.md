## Coder 的优势（不需要改变的）

1. **桌面应用体验**：多面板布局（聊天+文件树+编辑器+终端），信息密度高
2. **富文本输入**：TipTap + @提及 + 拖放，输入体验优于终端
3. **代码编辑**：Monaco 编辑器提供完整编辑体验
4. **自动化系统**：Cron 调度 + 执行锁 + 运行历史，Claude Code 没有此功能
5. **多提供商支持**：原生支持任意 OpenAI 兼容 API，不绑定单一供应商
6. **国际化**：i18n 中英双语支持
7. **主题系统**：亮暗模式切换
8. **可自定义快捷键**：灵活的键盘快捷键系统
9. **Plan CRUD 工具集**：6 个 Plan 工具提供完整计划管理

## 核心设计哲学差异总结

| 维度 | Coder 哲学 | Claude Code 哲学 |
|------|-----------|-----------------|
| **用户模型** | 桌面开发者（需要 GUI、编辑器、终端） | 终端开发者（习惯 CLI、SSH、远程） |
| **扩展性** | 内置功能优先（自动化、计划、技能） | 协议优先（MCP、Hooks、Plugins） |
| **上下文策略** | 交接（干净重置） | 压缩（保持连续性） |
| **安全模型** | 模式过滤（简单高效） | 规则引擎（精细可控） |
| **架构风格** | 前端驱动（React SPA） | 后端驱动（CLI + AsyncGenerator） |

两者各有优劣。Coder 在用户体验和桌面集成方面领先，Claude Code 在扩展性和工程深度方面更成熟。最佳策略是**保留 Coder 的 UI 优势，吸收 Claude Code 的工程深度**。
